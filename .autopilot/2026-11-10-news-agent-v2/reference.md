# Эталон для сравнения

## Формат Telegram-дайджеста

Источник: пользователь прислал образец от 26.08.2026 10:00 (последний живой выпуск
до потери сервера). Текст считается согласованным **по форме**; содержание того
выпуска — как раз то, что пользователь забраковал (см. «Что показал образец»).

### Структура (дословно по образцу)

```
🌅 Утренний дайджест научного агента
{26 августа 2026 г.}

За последние 24 часа опубликовано: {N}

🛠 ИИ-новости — {n1}
▫️ {Заголовок} ({url первоисточника}) — {выжимка до 180 символов}
▫️ …
Ещё {n1 − 7} материалов — в дашборде.

🔬 ИИ для науки — {n2}
▫️ …

🧪 Инструменты для изобретений — {n3}
▫️ …

📊 Дашборд доступен по кнопке ниже
{адрес дашборда}
```

- Порядок разделов фиксирован: ИИ-новости → ИИ для науки → Инструменты для изобретений.
- В разделе максимум 7 карточек, остальное — строкой «Ещё N … в дашборде».
- Длинное сообщение режется на несколько частей (лимит Telegram 4000 символов);
  вторая часть начинается сразу с карточки, без повторной шапки — так в образце.
- Имя «Ассистент для поиска технологий» — это имя бота в Telegram, не текст сообщения.
- Служебных строк (здоровье конвейера, ошибки) в образце нет — и по решению
  пользователя от 10.11 их быть не должно: «клиент о них знать не должен».

### Что показал образец (не форма, а содержание)

Выпуск 26.08 — сам по себе эталон ошибки, которую надо устранить:

- опубликовано **100** материалов за 24 часа (78 / 17 / 5) — при согласованном
  бюджете 5–10 в день;
- в «ИИ-новости» лежат материалы вообще без ИИ: композиты Пермского Политеха,
  антипирены ПБДЭ, аппроксимация идеального наблюдателя;
- в «ИИ для науки» лежат ИИ-новости и продукты: StarHarness (агентные обвязки),
  KGQA по графам знаний, ИИ в финансовом анализе, браслет AgeLab, чат-боты MIT;
- в «Инструменты для изобретений» лежат не-инструменты: паутина для eDNA,
  робо-карнавал в Шанхае, колонка «ИИ в науке требует рассуждений»;
- формулировка «Ещё 71 новостей материалов по теме — в дашборде» сломана грамматически.

Вывод для работы: форма фиксируется по образцу, содержание переделывается заново.
Образец снят со сборки, которая старше текущего кода (в нынешнем коде другая
формулировка строки «Ещё N» и ссылки сделаны гиперссылкой) — поэтому формат
подтверждается вопросами, а не догадками.
