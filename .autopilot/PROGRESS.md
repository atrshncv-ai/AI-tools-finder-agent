# Научный агент — что осталось

Последняя сборка: `.autopilot/2026-11-10-news-agent-v2/` — v2 (отбор, GigaChat, бюджет, дайджест) + развёртывание на сервере.

## Договорились — не пересматривать

- Три раздела неизменны: «ИИ-новости», «ИИ для науки», «Инструменты для изобретений»; точность судится по направлениям.
- Бюджет дня 5–10 публикаций (по умолчанию 8), проверяется и на публикации.
- «Лучше пропустить, чем промахнуться»: судья отказывает при сомнении, ошибка разбора = отказ.
- Провайдер: GigaChat основной, OpenCode Go — только фолбэк на квоту и транзиентные сбои.
- Клиент не видит служебных строк; ошибки и счётчики — только владельцу.
- Один выпуск в сутки; дайджест 09:00 МСК.

- Сервер FirstVDS, Москва: Ubuntu 24.04, 2 ядра, 3.8 ГБ RAM, 59 ГБ SSD, `45.10.218.38`, хост `sointreid.fvds.ru`.
- Стек: Node 20, PostgreSQL 16.15, PM2 (web + ralph-loop), nginx, ffmpeg, yt-dlp, deno.
- Доступ: только по ключу `~/.ssh/news_agent_server`; вход по паролю отключён, пароль из переписки обезврежен.
- Файрвол: 22/80/443; лишние порты образа (FTP, почта, панель, DNS) убраны; fail2ban активен.
- Приложение: `/srv/news-agent`, пользователь `deploy`, `.env` с правами 600.
- База: 11 таблиц, сиды (11 категорий, 12 инструментов, 140 источников).
- Живой цикл проверен: собрано 112 → в окне 52 → в базу 50 → префильтр 21 → судья 9 → одобрено 1 → опубликовано 1 (русский заголовок и выжимка от GigaChat, ошибок провайдера 0).
- Дайджест собран по эталону; служебный отчёт владельцу показывает расход токенов.

## Не доделано

- **chat_id получателей.** Бот `@ai_science_finder_bot` создан, токен в `.env`; никто ещё не нажал /start, поэтому доставка выключена.
- **Домен и HTTPS** — дашборд пока по `http://45.10.218.38`, без шифрования.
- **Бэкап вне сервера** — скрипт и cron стоят, но нужны `BACKUP_S3_*` (аккаунт хранилища).
- **Учётки дашборда** созданы с локальными адресами `owner@` и `client@news-agent.local` — заменить на настоящие, если понадобится.
- **Низкий выход**: порог балла 50 режет одобренных судьёй (у них 40–45), поэтому за сутки проходит 1–2 вместо 5–10. Нужно решение: заполнять бюджет одобренными судьёй с нижней планкой ~35 либо оставить строго.

## Известные баги

- Deep-link в SPA отдаёт 404 на стороне приложения; закрыто fallback-ом в nginx (`@spa_fallback`), в коде не исправлено.
- Telegram с сервера работает только через закреплённый IP `149.154.167.220` в `/etc/hosts`: из трёх адресов Telegram открыт один.
- Сертификаты Минцифры приходят с CRLF и ломают OpenSSL 3 — bundle собирается вручную (`/etc/ssl/certs/news-agent-russian-trusted.pem`, только корневой).
- Выжимка от модели бывает длиннее 180 знаков; форматер режет по границе слова, но промпт длину не удерживает.
- Жёсткий ИИ-гейт оценки читает первые 1500 знаков страницы и может отклонить одобренное судьёй.
- Повтор после неудачной публикации платит за вторую порцию выжимок.
- `check-gigachat.sh` и `backup-offsite.sh` передают секрет аргументами (видно в `ps`).
