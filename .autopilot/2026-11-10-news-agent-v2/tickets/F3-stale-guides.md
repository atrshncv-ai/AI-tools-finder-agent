## Что должно заработать

Ни один документ в репозитории не описывает вход через Kimi OAuth, локальную модель LM Studio
или прямые вызовы Zen — этих вещей в коде нет. Руководство пользователя описывает вход по
логину и паролю, руководство API — текущий контракт tRPC.
