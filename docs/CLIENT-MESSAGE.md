Здравствуйте! Чтобы запустить сервис, нужно два доступа — оба оформляются в браузере, займёт около 15 минут.

**1. GigaChat** — нейросеть, которая пишет выжимки новостей.

1. Откройте https://developers.sber.ru/studio/workspaces/my-space/get/gigachat-api и войдите по Сбер ID (подойдёт обычный аккаунт Сбера).
2. Слева нажмите «Создать проект» → раздел «AI-модели» → «GigaChat API» → название любое → примите условия соглашения.
3. В проекте слева откройте «Настройки API» → кнопка «Получить ключ».
4. Скопируйте и сохраните три значения — они показываются только один раз:
   • Authorization Key
   • Client ID
   • Client Secret
5. В правой панели проверьте поле «Scope» — там должно быть `GIGACHAT_API_PERS`.

Бесплатный лимит на 365 млн токенов подключится автоматически и действует год.

**2. Сервер** — машина, на которой всё будет работать.

1. Закажите на firstvds.ru готовый тариф «Разгон»: 2 ядра, 4 ГБ RAM, 80 ГБ SSD — 919 ₽/мес.
2. Локация — Москва. Операционная система — Ubuntu 24.04.
3. После создания сервера возьмите в панели IP-адрес и пароль root.

**Что прислать мне** — всего пять пунктов:

1. Authorization Key
2. Client ID
3. Client Secret
4. IP-адрес сервера
5. Пароль root

Пароли и ключи присылайте через менеджер паролей или одноразовую ссылку, а не в открытом чате — это пароли от ваших токенов и сервера. Пароль root временный: мы сразу заменим его на ключ доступа.

Если понадобится домен — скажите отдельно, `.ru` у них стоит 450 ₽/год.

Если кнопка «Получить ключ» неактивна — у вашей учётной записи роль «Наблюдатель»; ключ могут выдать только владелец или администратор проекта.

## Для владельца — что проверено

- «Разгон» в Москве на SSD — 919 ₽/мес; вариант на NVMe стоит 1 069 ₽/мес.
- Тарифы «Старт» (519 ₽) и «Прогрев» (299 ₽) в Москве сейчас в статусе «нет в наличии».
- У FirstVDS есть своё S3-хранилище от 250 ₽/мес — кандидат под бэкапы вне сервера.
- В их FAQ есть предупреждение, что Telegram API недоступен с серверов в Москве. Проверяется одной командой сразу после выдачи сервера; решение о прокси принимается по факту, а не заранее.
