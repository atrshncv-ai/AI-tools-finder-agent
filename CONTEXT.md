# CONTEXT.md — словарь системы за десять минут

Документ для нового человека и для нового агента: что здесь называется как, где
это лежит и что означает. Технические детали — в `ARCHITECTURE.md`, порядок
развёртывания — в `docs/DEPLOY.md`.

## Словарь

| Термин | Что это | Где живёт |
|---|---|---|
| **Раздел** | Контейнер выпуска и дашборда. Их ровно три, названия и порядок неизменны: «ИИ-новости», «ИИ для науки», «Инструменты для изобретений» | `SECTIONS` в `app/scripts/hermes/topics.ts` |
| **Направление** | Одна из шести областей науки внутри раздела «ИИ для науки»: химия, материаловедение, биология, медицина, физика, инженерия. Пользователь фильтрует дашборд по направлениям | `DIRECTIONS` в `app/scripts/hermes/topics.ts` |
| **Тема** | Смысл материала: про что он. Решается по определению раздела и направления, а не по совпадению слова | `topics.ts` (определения), `app/scripts/hermes/judge.ts` (решение) |
| **Префильтр** | Дешёвая детерминированная ступень отбора: заголовок и лид, AI-сигнал, свежесть, пустой заголовок. Не тратит токенов и не ходит в сеть | `app/scripts/hermes/prefilter.ts` |
| **Лид** | Описание материала из RSS, сохранённое при сборе (`news.summary` на момент сбора). По нему судят префильтр и судья; позже `summary` перезаписывается русской выжимкой | `app/scripts/hermes/collect-dual.ts` |
| **Судья** | LLM-проверка «материал действительно про эту тему». Возвращает `{onTopic, section, direction, confidence, reason}` и работает fail-closed: сомнение = отказ | `app/scripts/hermes/judge.ts` |
| **Вердикт** | Сохранённый ответ судьи в `news.metrics.judge` (`onTopic/section/direction/confidence/reason/provider/model`). Повторно за ту же статью судья не платит | `news.metrics` |
| **Бюджет дня** | Жёсткий предел числа публикаций за UTC-сутки: 5..10, по умолчанию 8 (`DAILY_BUDGET`). Проверяется и при отборе, и при публикации | `app/scripts/hermes/publish-budget.ts` |
| **Бюджет скачиваний** | Сколько страниц цикл ещё может скачать сегодня. Страница качается только для прошедших префильтр, судью и этот бюджет | `app/scripts/hermes/evaluate-news.ts` |
| **Балл** | Число 0..95 от детерминированного скоринга (источник, цифры GitHub/HN, arXiv, altmetric, видео). Гейт — `SCORE_GATE` (50) | `app/scripts/hermes/pipeline-config.ts` |
| **Гейт** | Единственный порог публикации. Второе такое число в другом файле — дефект | `SCORE_GATE` в `pipeline-config.ts` |
| **Цикл** | Один проход конвейера за UTC-сутки, `cycle-YYYY-MM-DD`. Повтор после сбоя продолжает тот же цикл | `pipeline_state.cycleId` |
| **Выпуск** | Опубликованный набор статей дня, `news.status='published'`. Один выпуск в сутки; второму взяться неоткуда | `app/scripts/hermes/deploy-ready.ts`, `docs/adr/0004-one-release-per-day.md` |
| **Дайджест** | Утреннее сообщение в Telegram по вчерашним публикациям: шапка, дата, счётчик, три раздела, карточки, «Ещё N материалов», футер с адресом дашборда | `app/scripts/hermes/digest-format.ts` |
| **Клиентский выпуск** | Чистый дайджест для заказчика. В нём нет ни ошибок, ни счётчиков, ни строки здоровья | `buildClientDigest()` |
| **Служебный отчёт** | Отдельное сообщение только владельцу: собрано / отсеяно префильтром / отсеяно судьёй / опубликовано, топ-3 причины отказа, ошибки, расход токенов | `buildOwnerReport()` |
| **Получатели** | Адреса доставки: `TELEGRAM_CLIENT_CHAT_IDS` (клиент) и `TELEGRAM_OWNER_CHAT_IDS` (владелец). Старые `TELEGRAM_CHAT_IDS`/`TELEGRAM_CHAT_ID` — фолбэк для клиента | `resolveRecipients()` в `app/scripts/hermes/digest-format.ts` |
| **Провайдер** | Источник LLM-ответов: GigaChat (основной) или OpenCode Go (фолбэк). Классы ошибок: `config`, `quota`, `transient`, `content` | `app/api/ai/providers/` |
| **Цепочка** | Порядок провайдеров и правило перехода: quota/transient → следующий, config → ошибка наверх | `app/api/ai/providers/chain.ts` |
| **Метрики цикла** | Счётчики дня в `pipeline_state.metrics`: `collected`, `prefiltered`, `judged`, `approved`, `published`, `rejectedByReason`, `usage` | `publish-budget.ts` |
| **Счётчик расхода** | Токены, которые вернул провайдер: `calls`, `inputTokens`, `outputTokens`. Никогда не выбрасываются | `pipeline_state.metrics.usage` |
| **Бэкап вне сервера** | Ночной дамп базы, уехавший в S3-совместимое хранилище. Копия на самом сервере бэкапом не считается | `scripts/backup-offsite.sh` |
| **G02** | Ограничение прогона: адрес сервера, домен и доступы придут от владельца. Развёртывание — заглушка, runbook и скрипты готовы | `.autopilot/`, `PROGRESS.md` |

## Как течёт новость

```
источник → collect-dual.ts → news(pending) → префильтр → судья → бюджет дня
        → скачивание страницы и балл → manifest-gen → fetch-article
        → save-summary (русский заголовок + выжимка) → deploy-ready
        → news(published) → daily-digest 06:00 UTC
                             ├→ клиент: чистый выпуск
                             └→ владелец: копия + служебный отчёт
```

Правила, которые нельзя нарушать по дороге:

1. **`originalUrl` неприкосновенен.** LLM не возвращает URL; ссылка в выпуске —
   всегда из базы.
2. **Тело статьи — недоверенные данные.** Оно обёрнуто маркерами
   `--- BEGIN ARTICLE (UNTRUSTED) ---` / `--- END ARTICLE ---`.
3. **Клиент не видит служебных строк.** Всё про здоровье, ошибки и счётчики —
   только владельцу.
4. **Судья видит заголовок и лид**, а не только заголовок: промахи 26.08
   начинались именно с суждения по одному заголовку.
5. **Бюджет дня проверяется на публикации**, а не только на отборе.
6. **Один выпуск в сутки.** Повтор разрешён только при сбое.
7. **Секреты только в `.env`.** В коде, тестах и документации — имена переменных.

## Кто есть кто в коде

| Модуль | Ответственность |
|---|---|
| `app/scripts/hermes/ralph-loop.sh` | оркестратор: один цикл в сутки, повтор после сбоя |
| `app/scripts/hermes/topics.ts` | единственное описание разделов и направлений |
| `app/scripts/hermes/prefilter.ts` | дешёвый отбор до дорогих вызовов |
| `app/scripts/hermes/judge.ts` | LLM-судья, fail-closed |
| `app/scripts/hermes/evaluate-news.ts` | префильтр → судья → бюджет → скачивание → балл |
| `app/scripts/hermes/publish-budget.ts` | бюджет дня, журнал цикла, CLI состояния |
| `app/scripts/hermes/manifest-gen.ts` | манифест лучших в пределах бюджета |
| `app/scripts/hermes/save-summary.ts` | русский заголовок и выжимка одним вызовом |
| `app/scripts/hermes/deploy-ready.ts` | единственная публикация, последняя проверка бюджета |
| `app/scripts/hermes/digest-format.ts` | формат клиентского выпуска и служебного отчёта |
| `app/scripts/hermes/daily-digest.ts` | выборка за 24 часа и доставка двум аудиториям |
| `app/api/ai/providers/` | GigaChat, OpenCode, цепочка, классы ошибок |
| `app/skills/news-processor/SKILL.md` | алгоритм конвейера для агента-исполнителя |
